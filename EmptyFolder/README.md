Система управления миграциями базы данных через HTTP API
Доступные методы API
GET /migrate/create
Формирует SQL-скрипты миграции согласно текущим моделям данных

GET /migrate/apply
Выполняет последнюю сгенерированную миграцию в базе данных

GET /migrate/rollback
Отменяет последнюю выполненную миграцию с помощью down-скрипта

GET /migrate/status
Отображает текущий статус миграций и расхождения моделей с БД

GET /migrate/log
Показывает полную историю применённых миграций

Используемые технологии: C#, PostgreSQL, HttpListener, JSON
